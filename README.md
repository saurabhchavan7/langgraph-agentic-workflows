# LangGraph Agentic Workflows

This repository contains hands-on implementations of agentic AI workflow patterns using LangGraph. The goal is to understand how graph-based orchestration can be used to build stateful, multi-step, and tool-augmented LLM applications.

## Why this repo

LangGraph is useful for building AI systems where the workflow is not just a single LLM call. Real agentic systems often need state, branching, loops, memory, tools, persistence, and human feedback. This repo captures those patterns through small, focused examples.

## Topics Covered

- Sequential workflows
- Parallel workflows
- Conditional workflows
- Iterative workflows
- Chatbot workflows
- Persistence and time travel
- Streaming responses
- Tool calling
- RAG workflows
- Human-in-the-loop workflows
- Subgraphs
- Short-term and long-term memory
- Corrective RAG and Self-RAG patterns
